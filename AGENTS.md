# refer.nvim — Agents Context

## Overview

refer.nvim is a fuzzy picker for Neovim (0.10+) written entirely in **Lua**.
It provides `refer.pick()` / `refer.pick_async()` as a lightweight alternative to Telescope, with pluggable sorters (blink, mini.fuzzy, native vim.matchfuzzy, pure Lua) and providers (buffers, files, live_grep, LSP, commands, help tags, etc.).

## Commands

```sh
make test          # Run all tests via PlenaryBustedDirectory
stylua lua/ tests/ # Format all Lua files
pre-commit run -a  # Run all hooks (StyLua check + YAML lint)
```

## Code Style

`.stylua.toml` governs formatting: 4-space indent, 120 columns, double quotes, no parentheses on calls. Run `stylua lua/ tests/` before committing.

- `snake_case` for functions and variables, `UpperCamel` for class-like tables.
- Prefix internal-only helpers with `_` and expose under `M._fn` for testing.
- `vim.validate` for user-facing API inputs.
- `pcall(require, ...)` for optional dependencies.
- **No explanatory comments by default** — LuaCATS annotations are required, but avoid extra prose comments unless the code is genuinely non-obvious or a complex edge case needs clarification. The code should speak for itself; trust naming and structure over inline prose.

## Module Pattern

```lua
function M.public_fn() end

return M
```

## Documentation

All public functions must have **LuaCATS** (`---@`) type annotations for every parameter and return value:

```lua
---Filter items based on query
---@param items_or_provider table|fun(query: string): table List of strings/ReferItems or a provider function
---@param query string The search query
---@param opts table Options { sorter = function, use_blink = boolean }
---@return ReferItem[] matches List of matching ReferItem tables
function M.filter(items_or_provider, query, opts)
```

- Use `---@class` / `---@field` for object types, `---@alias` for union types, `---@type` for inline type hints.
- Internal helpers (prefix `_` or local) should also be annotated for maintainability.
- Options tables should be typed as a `@class` with `@field` entries (see `ReferOptions` in `lua/refer/init.lua`).

## User Documentation

When changing public APIs, commands, keymaps, options, providers, or user-facing behavior, update `README.md` and relevant source docs under `docs/` as appropriate. Do not edit `doc/refer.nvim.txt` by hand; it is generated by `.github/workflows/docs.yml` using panvimdoc.

## Runtime Expectations

- Target Neovim 0.10+.
- Primary language is Lua.
- Optional integrations must degrade gracefully when unavailable.
- External tools such as `fd`/`fdfind` and `rg` should be checked before relying on them.

## Test Patterns

- **Framework**: `plenary.busted` (via `tests/minimal_init.lua` which clones plenary.nvim).
- **File naming**: `tests/refer/<module>_spec.lua`, `regression_<issue>_spec.lua` for bug regressions.
- **Structure**:
  ```lua
  describe("module", function()
      local picker

      before_each(function()
          picker = refer.pick({}, function() end)
      end)

      after_each(function()
          if picker then
              picker:close()
          end
      end)

      it("does thing", function()
          assert.are.same(expected, actual)
          assert.is_true(condition)
      end)
  end)
  ```
- **Mocking**: `require("luassert.stub")` → `stub(vim.fn, "fn")` / `fn:revert()`.
- **Async tests**: Use `vim.wait(timeout, condition_fn)` for polling.
- **Regression tests**: Add or update `regression_<issue>_spec.lua` when fixing bugs that could recur.

## Architecture

- **ReferItem contract**: `{ text = string, data = any|nil }` — `text` is the fuzzy-sorted display string, `data` is an opaque payload.
- **Provider pattern**: A function returning items or a command generator. Pass `provider = "name"` in opts for frecency scoping.
- **Sorter registry**: `fuzzy.sorters[name]` — four built-in (`blink`, `mini`, `native`, `lua`). Custom ones via `fuzzy.register_sorter(name, fn)`.
- **Async picker**: `refer.pick_async(cmd_generator, on_select, opts)` streams via `vim.system` with debounce.
- **Parser schema**: `util.register_parser(name, { pattern = "..", keys = {..}, types = {..} })` for extracting filename/lnum/col.
- **Frecency**: Post-sort reordering (Mozilla buckets), per-provider, opt-out, neighborhood-based (groups of ~10), only on `lua` sorter. No-op if `vim.sqlite` missing.
